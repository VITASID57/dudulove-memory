# DuduLove Memory

为 AI 和个人 Agent 保存、找回和管理长期记忆。

在自己的电脑或服务器上运行，为每个 AI 建立独立的记忆身份。连接不同客户端时，身份、记忆和授权保持一致。内置管理网页，可从电脑和手机查看、编辑资料。

## 开始使用

需要 Node.js 22.13 或更新版本。

```sh
npm ci --ignore-scripts
npm start
```

1. 浏览器打开终端显示的地址（默认 `http://127.0.0.1:8787`），设置管理密码。
2. 点击「＋ 记忆身份」，取一个名字，保存第一条记忆。
3. 在「身份与连接」复制连接，填写到支持 MCP 或 HTTP API 的客户端。

记忆保存在本机 `data/` 目录。需要跨设备访问时，按[部署说明](docs/operations.md)配置 HTTPS 地址。

## 主要功能

| 功能 | 用途 |
| --- | --- |
| 独立身份 | 每个身份有固定 ID、自己的长期记忆和日常碎片；改名与更换客户端保持原归属。 |
| 共享资料 | 共同使用世界观、知识、工程经验和明确共享的近况。 |
| 搜索与召回 | 关键词搜索即装即用；按话题组合相关记忆交给 AI，语义搜索可按需开启。 |
| 编辑与恢复 | 编辑保留原记录时间，另记修改时间和历史；误删进入回收站，可恢复。 |
| 工作助手 | 工作召回侧重规则、项目经验、已记录的待办与近期行动；用户可授予指定身份的只读权限。 |
| 资料整理 | 将碎片或导入的聊天文字整理成可编辑的小结，保留原文；支持按身份开启周期整理。 |
| 活动与简报 | 记录行动结果，生成近期简报，并按客户端分别保存简报接收进度。 |

整理和语义搜索使用自行配置的 OpenAI 兼容模型接口。启用前可查看资料发送范围与调用条件；基础记录、搜索和管理可直接使用。
