# 验证情况

0.1.0 的验证使用空数据目录与虚构资料。

## 自动检查

`npm test` 包含 30 项测试，覆盖真实服务登录、身份隔离、HTTP 与 MCP 读写、客户端身份绑定、编辑冲突与历史、恢复、重启持久化、简报回执、活动、工作召回、实时授权与撤销、聊天文件读取和完整数据目录恢复。

整理与语义检索的自动回归使用本地模拟供应商，覆盖来源变化、撤销、接口失败与关键词回退。基础存取在模型未配置时完成验证。

`npm run check` 检查语法、模块边界、循环依赖、文件规模和发布文件。`npm run pack:release` 核对压缩包文件清单，并生成 SHA-256 校验。

## 模型实测

已用实际配置的 OpenAI 兼容接口处理虚构材料：整理预览返回有效小结；向量索引建立成功，换用相关语义查询可找回原文。不同服务商的协议细节、可用模型和限额需按其实际支持配置。

## 使用环境

本地服务与测试使用 Windows、Node.js 24.14。持续集成配置使用 Linux、Node.js 22。浏览器管理页的电脑与手机布局按创建身份、授权、记录、编辑和导入流程检查。MCP 通过 SDK 的 HTTP 与 stdio 客户端验证；各客户端配置格式见接入文档。
