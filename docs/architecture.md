# 模块与数据流

网页、HTTP API 与 MCP 使用同一套身份校验、记忆读写和召回逻辑。

| 目录 | 职责 |
| --- | --- |
| `memory-core` | 身份授权、记忆规则、召回、整理、活动与简报 |
| `storage` | 本地数据文件与检索 |
| `services` | 可重试的写入流程 |
| `routes` | HTTP 参数与响应 |
| `connectors` | MCP 与客户端发现/绑定接口 |
| `platform` | 服务配置、登录和请求身份 |
| `public` | 管理网页 |
| `tests` | 隔离的真实服务与接口验证 |
| `scripts` | 源码检查与发布包 |

每次请求根据连接口令确定身份，读取时加载当前授权，写入校验所属身份。编辑保留原时间，并留存编辑日志。

记忆先保存，再异步建立可选的向量索引。检索组合关键词与可用的语义结果。整理小结保留来源引用，原记录可以独立使用。

数据集中在配置目录，包括 `memories.db`、`settings.db`、`access.json`、`memory_audit.db`、`embeddings.db` 和整理、聊天等模块数据。以整个目录为单位备份。

`npm run check` 检查语法、依赖方向、循环依赖、文件规模和发布内容。发布文件由 `scripts/files.js` 明确选择。
