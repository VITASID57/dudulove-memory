# 日常使用

## 身份与资料

在管理网页点击「＋ 记忆身份」，填写名字并选择召回方式。每个身份建立自己的资料空间和固定 ID。在「身份与连接」改名，已有资料和连接继续对应同一身份。

| 分类 | 适合保存 | 可见范围 |
| --- | --- | --- |
| 长期记忆 `private` | 偏好、经历、日记、项目经验、办事规则 | 本人及用户授权的读取者 |
| 日常碎片 `pulse` | 随手记录的日常近况 | 默认本人；明确选择共享后共同可读 |
| 共享世界观 `world` | 共同设定、背景与知识 | 所有身份 |
| 工程经验 `ops` | 可复用的工具用法和技术经验 | 所有身份 |

工作助手的私人工作笔记同样存入长期记忆。共享分类在管理页有说明，保存前核对归属。

## 记录、查找与编辑

点击「记一笔」，填写标题、内容和分类即可。搜索可结合关键词、身份和分类；保存的记录即可参与查找。AI 调用召回接口后，客户端把返回的 `contextText` 放进当前模型上下文。

编辑保留 `createdAt`，另外更新 `updatedAt` 并保存编辑历史。它们分别表示记录时间和编辑时间，事件发生时间以正文为准。删除的记录进入回收站，点击恢复可重新使用。

## 对话和工作召回

对话召回关注自己的身份、偏好与当前话题相关的经历。工作召回关注办事规则、项目经验、明确标记的未完事项和近期行动结果。

工作笔记可通过接口设置 `type: "project"` 或 `"tool"`、`projectId` 和 `lifecycle: "open_loop"`。处理完成后将 `lifecycle` 更新为 `"active"`，并记录结果。未完事项是记忆中的状态，执行前仍需核对实际情况。

## 授权工作助手查阅

选择工作助手，在「身份与连接」设置读取范围：本人和共享、指定身份、全部身份。指定模式下新增身份需要单独勾选；全部模式覆盖以后新增的身份。

授权按固定 ID 保存。助手读取别人的资料时，结果带有原归属；自己的身份段落仍来自本人记忆。授权用于查阅记忆，其他身份的增改删、整理、原始聊天材料和活动记录保持各自隔离。保存授权后，各客户端的后续请求采用最新配置；已经交给客户端的内容由客户端管理。
