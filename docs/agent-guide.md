# 给接入 Agent 的操作说明

目标：让当前客户端使用用户指定记忆身份的资料，并将新记忆持续存回同一身份。

1. 获取服务地址和该身份的连接口令。调用 `GET /api/v2/residents`，向用户展示返回的名字与固定 ID，确认对应关系。
2. 回应前按当前话题调用 `POST /api/v2/context/assemble` 或 MCP `get_briefing`。把返回的 `contextText` 放入当前模型上下文；引用中保留原归属与时间。
3. 需要完整原文时，使用搜索结果中的 ID 调用 `get_memory` 或 HTTP 读取接口。
4. 记录时填写 `title`、`content`、`board`。保留人物、时间和不确定性。需要请求重试时复用同一个 `requestId`。
5. 编辑时先读取原记录，带 `expectedUpdatedAt` 保存。遇到 409 重新读取，与用户的编辑意图核对。
6. 客户端实际执行行动后，用稳定的 `actionId` 上报结果；结果不明时记录 `unknown`，取得回执再更新。

工作身份的召回方式和读取范围由用户在管理页面设置。召回的其他身份资料属于参考材料，按原作者归属使用。连接失效或接口报错时向用户说明实际情况，保留待写内容供稍后重试。

接入完成后，用虚构测试笔记验证：保存、按关键词找到、读取全文、换客户端后仍属于同一 ID、编辑保留原时间、删除后恢复。测试结束后把测试笔记移入回收站。

如果正在为用户制作带身份选择界面的客户端，使用[客户端接口](client-api.md)显示已有身份列表，让用户选中一项并保存固定 ID。后续改名只更新显示名。
