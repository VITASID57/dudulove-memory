# 部署、备份与维护

## 安装

安装 Node.js 22.13 或更新版本，解压发布包或下载源码，在目录执行：

```sh
npm ci --ignore-scripts
npm start
```

终端显示访问地址。首次打开网页设置管理密码，再创建记忆身份。

## 配置与远程访问

将 `.env.example` 复制为 `.env`，按需要修改：

| 变量 | 用途 |
| --- | --- |
| `HOST` | 默认 `127.0.0.1`，由本机反向代理提供 HTTPS。 |
| `PORT` | 默认 `8787`。 |
| `MEMORY_DATA_DIR` | 数据目录，默认 `./data`；长期部署建议用固定绝对路径。 |
| `MEMORY_ADMIN_TOKEN` | 可选的管理口令，至少 16 字符，适合无交互部署。 |
| `MEMORY_ALLOWED_ORIGINS` | 允许浏览器直接访问接口的其他站点来源，逗号分隔。 |

先完成首次密码设置，再开放远程访问。服务器上用 Caddy、Nginx 等将 HTTPS 请求转发到本机端口；MCP 使用流式 HTTP，代理须允许长连接并关闭响应缓冲。示例域名为 `https://memory.example`。

浏览器里的 `127.0.0.1` 指浏览器所在设备。手机与其他电脑使用服务的实际地址。原生 HTTP 与 MCP 客户端携带身份 Bearer 口令；浏览器跨站接入同时配置准确的来源。

## 备份与恢复

完整备份整个数据目录，包括身份与口令、记忆、编辑历史、聊天材料、活动、简报进度、模型配置和索引。另行保存部署所需 `.env`，按敏感资料保管。

1. 通过 `Ctrl+C` 或服务管理工具停服，等进程退出。
2. 复制整个数据目录到新备份目录，再重新启动服务。
3. 恢复时先安装相同版本，停服状态下将备份复制到空数据目录，用 `MEMORY_DATA_DIR` 指向它。
4. 启动后核对原身份 ID、记忆、历史、授权及旧客户端连接。

Windows 示例（服务已停止，`backups` 父目录已存在，目标日期目录尚未使用）：

```powershell
Copy-Item -LiteralPath './data' -Destination './backups/2026-10-05' -Recurse
```

Linux/macOS 可用文件管理器或 `cp -R data backups/2026-10-05` 完成相同复制。

## 升级

阅读版本说明，停服并备份数据与 `.env`。将新版程序放在新目录，执行 `npm ci --ignore-scripts`，配置它指向原数据目录，再启动检查。保留旧程序和升级前备份，以便恢复。

需要退回时，停服后使用旧程序和相配的升级前数据备份。涉及数据格式变化的版本会在版本说明中列出步骤。

## 常见问题

- **搜索不到**：检查身份、分类及关键词。语义服务未配置或故障时，关键词搜索仍可用。
- **模型返回 401**：检查 API 基址、模型和密钥是否属于同一服务。
- **403**：检查身份授权或浏览器来源配置。
- **409**：资料在读取后被更新，重新打开最新内容再编辑。
- **无法连接**：先访问 `/health` 检查服务，再检查部署地址、HTTPS 代理和客户端口令。
